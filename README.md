# Desafio HTML e CSS

Pagina feita para o desafio de criar e estilizar uma pagina HTML/CSS e publicar no GitHub Pages, para a Universidade Mogi das Cruzes.

## Tema

Jogos favoritos (Minecraft, GTA 5, God of War).

## O que tem na pagina

- header com titulo
- main com as secoes de texto e os cards dos jogos
- footer
- imagens dos jogos (pasta img)
- estilizacao com CSS (cores, bordas, espaçamento)

## Arquivos

- index.html
- style.css
- img/ (imagens usadas na pagina)

## Como ver

Utilize o Link do GitHub Pages, Você também pode clonar o repositório e alterar da forma que preferir.
