# Desafio HTML e CSS

Pagina feita para o desafio de criar e estilizar uma pagina HTML/CSS e publicar no GitHub Pages.

## Tema

Jogos favoritos (Minecraft, GTA 5, League of Legends).

## O que tem na pagina

- header com titulo
- main com as secoes de texto e os cards dos jogos
- footer
- imagens dos jogos
- estilizacao com CSS (cores, bordas, espaçamento)

## Arquivos

- index.html
- style.css

## Como ver

E so abrir o index.html no navegador, ou acessar pelo link do GitHub Pages.
